Legend & glossary

Stage colors & icons

Every entry in a mandate's timeline is accented (left border, icon, dot) by the color for its stage below. Where a stage has more than one possible color (classification, plan, execution), the color depends on the outcome shown next to it.

Failure event
A mandate debit failed and was injected into the pipeline.
Classification — rule
Classified by a deterministic taxonomy lookup, no LLM call.
Classification — LLM
P3/P12 only: genuinely ambiguous, routed to the Groq model. Card background is tinted and reasoning is shown inline.
Plan — retry
Planner selected a cost/probability-scored retry sequence.
Plan — escalate
No viable retry candidate; the plan hands off to the fallback agent.
Execution — success
A scheduled retry attempt succeeded against the (test-mode) payment API.
Execution — failed
A scheduled retry attempt was executed and declined.
Execution — pending / no-op
Not yet executed, or blocked as a duplicate/concurrent no-op (S3/S4).
Fallback message
The customer/merchant-facing message generated for an escalation.
Audit log
A system-level event (backoff retry, reclaimed stuck row, etc.) correlated onto this mandate's timeline.

Badges

Badges sit next to an entry's label and are scannable without reading the surrounding text. Hovering (or tapping) the same badges inline in the timeline shows this same text — pulled from /api/glossary, not duplicated by hand.
